 Scenario Description
This Dart program simulates an online checkout system for a customer ordering items. It should calculate the total costs using integer division (`~/`) and modulo (`%`), and evaluates free shipping eligibility using a comparison operator (`>=`).

Requirements Covered
- Data Types: Explicitly uses `int`, `double`, `String`, and `bool`.
- Operators: Employs arithmetic operators (`*`, `~/`, `%`) and a comparison operator (`>=`).
- I/O: Prints clear, labeled output using string interpolation.

 How to Run
Ensure you have the Dart SDK installed, then run the following command in the project root folder:

dart run
